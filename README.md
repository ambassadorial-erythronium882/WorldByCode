## 📖 About This Tool

WorldByCode takes a simple static image and transforms it into a 3D environment. You do not need to model objects or draw shapes. The software uses visual intelligence to understand what it sees in your picture. It then writes the code to build that scene in a simulated 3D space. You can interact with these objects, move them, and test physics inside your browser. This tool helps researchers and hobbyists test robot movements or create digital simulations without manual design work.

## 🛠️ Frequently Asked Questions

**Does this require 3D modeling skills?**
No. You do not need to know how to create 3D meshes or use design software. The system builds everything from the information in your 2D image.

**How does it handle different image types?**
It performs best with clear photos of objects, buildings, or rooms. It may struggle with abstract art or blurry pictures.

**Can I export my project?**
Yes. Use the "Export" menu to save your work as a file that you can share with others.

**Is my data private?**
The software processes your images locally on your machine whenever possible. This keeps your files on your computer rather than sending them to a third-party server.

## 📂 Understanding the Physics

The simulation uses a physics engine to calculate how things fall, bounce, or roll. If you see items moving through each other, try reducing the complexity of the initial image. You can adjust the "Friction" and "Bounce" settings in the properties panel to make the simulation feel more realistic. These sliders change the code in the background, which changes how the objects respond within the browser.

## 🌐 How the Technology Works

Many tools require artists to build 3D objects by hand. WorldByCode skips this step. It employs a technology called a Vision-Language Model. This model looks at your image and translates the visual features into a language the computer understands. It then maps these features to physical properties defined in the simulation engine. The software assembles these objects in a 3D environment automatically. This removes the need for manual setup and lets you focus on the outcome.
